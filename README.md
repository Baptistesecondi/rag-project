# RAG on national defence doctrines

A retrieval-augmented generation (RAG) pipeline that answers questions about 20 national security and defence strategy documents from China, France, Spain, the United Kingdom and the United States (2008–2025).

Three retrieval methods are implemented and compared: a BM25 index written from scratch in pure Python, dense retrieval with sentence embeddings, and a hybrid of both. Answers are generated by Claude through the Anthropic API, with numbered citations to the source passages. Without an API key, the tool returns the most relevant passages instead.

## Results

Retrieval is evaluated on two hand-written question sets, each question linked to the document(s) that contain the answer:

- **Keyword questions** (`data/eval/questions.json`, 14 questions): written from facts found by searching the documents, so they often reuse the source's wording.
- **Paraphrased questions** (`data/eval/questions_paraphrased.json`, 17 questions): written without the rare words of the source passage, as a user who has not read the text would ask, e.g. *English-speaking spy partnership* for *Five Eyes*, or *atomic bombs* for *nuclear weapons*.

Recall@3 (correct document among the top 3 passages):

| Method | Keyword questions | Paraphrased questions | Total (31) |
|---|---|---|---|
| BM25 | **86 %** | 41 % | 61 % |
| Dense | 64 % | **65 %** | 65 % |
| Hybrid (RRF) | 79 % | 53 % | 65 % |

- **BM25 depends on shared words.** It drops from 86 % to 41 % once questions are paraphrased, but wins on rare terms and proper nouns (*Golden Dome*, *Barkhane*, *Salisbury*).
- **Embeddings are stable across both sets.** They match meaning (*keep defence costs low* → *austerity*, *attacks on ships* → *piracy*), but dilute a single rare detail within a 200-word chunk.
- **The hybrid is the most balanced** and never the worst method. With equal weights, however, the fusion still loses some answers that the embeddings ranked 2nd or 3rd.

Five paraphrased questions are missed by all three methods: the answer shares no words with the question and requires inference (e.g. *fire the first shot* → *"We will not attack unless we are attacked"*). With 31 questions, one question is worth about 3 points, so differences of a few points are not significant.

### BM25 score threshold

A minimum BM25 score filters off-topic questions (e.g. *recipe for chocolate cake*). It was calibrated on the keyword set:

| Threshold | Recall@3 | Off-topic questions rejected |
|---|---|---|
| 0 | 86 % | 1/5 |
| **8 (default)** | **86 %** | **4/5** |
| 15 | 71 % | 5/5 |

A fixed threshold cannot separate all off-topic questions: *stock market prices today* scores higher than some relevant questions, because the corpus discusses markets and energy prices.

## How it works

1. **Ingestion** (`src/ingest.py`): loads `.txt` and `.md` files and splits them into 200-word chunks with a 40-word overlap.
2. **Retrieval**, three interchangeable methods:
   - BM25 (`src/retrieve.py`): k1 = 1.5, b = 0.75, after lowercasing and removing English stop words (`src/stopwords.py`).
   - Dense (`src/dense.py`): `BAAI/bge-small-en-v1.5` embeddings and cosine similarity, cached in `data/cache/`.
   - Hybrid (`src/hybrid.py`): Reciprocal Rank Fusion of the BM25 and dense rankings.
3. **Generation** (`src/generate.py`): builds a prompt with numbered sources and asks the model to answer only from them.
4. **Evaluation** (`src/evaluate.py`): computes Recall@k and MRR for each method on a question set, and sweeps the BM25 score threshold.

## Usage

Requires Python 3.10 or later.

```bash
# Tests (18 unit tests)
python -m unittest discover -s tests -v

# Ask a question (shows the retrieved passages without an API key)
python src/cli.py "Which country is the pacing challenge for the US Department of Defense?"

# Evaluate retrieval (BM25 only, without the optional dependencies)
python src/evaluate.py --method bm25
```

For written answers, install the optional dependency and set an API key:

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="your_key"
```

For dense and hybrid retrieval, install the embedding dependencies (the model, about 130 MB, downloads on first use):

```bash
pip install -r requirements-dense.txt
python src/evaluate.py                                                   # keyword questions
python src/evaluate.py --questions data/eval/questions_paraphrased.json  # paraphrased questions
python src/cli.py "your question" --method hybrid
```

## Data

The documents come from the [Military Doctrines dataset](https://jandresgannon.github.io/militarydoctrines/) (J Andrés Gannon, Vanderbilt University), which collects national security strategy documents in text format.
