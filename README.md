# RAG on national defence doctrines

A retrieval-augmented generation (RAG) pipeline that answers questions about 20 national security and defence strategy documents from China, France, Spain, the United Kingdom and the United States (2008–2025).

The retrieval layer is a BM25 index written from scratch in pure Python, with no external dependency. Answers are generated by Claude through the Anthropic API, with numbered citations to the source passages. Without an API key, the tool returns the most relevant passages instead.

## Results

Retrieval is evaluated on 14 hand-written questions, each linked to the document that contains the answer (`data/eval/questions.json`).

| Metric | Score |
|---|---|
| Recall@3 (correct document in the top 3) | **86 %** (12/14) |
| Mean reciprocal rank | **0.82** |

Both misses come from a vocabulary gap between question and source: the question says *undersea cables* where the document says *submarine cables*, and *keep defence costs low* where it says *austerity*. BM25 only matches exact words, which is the main motivation for comparing it with dense embeddings (see next steps).

A minimum score threshold filters off-topic questions. It was calibrated on the same question set:

| Threshold | Recall@3 | Off-topic questions rejected |
|---|---|---|
| 0 | 86 % | 1/5 |
| **8 (default)** | **86 %** | **4/5** |
| 15 | 71 % | 5/5 |

### BM25 vs dense embeddings

Dense retrieval uses `BAAI/bge-small-en-v1.5` (cosine similarity); the hybrid fuses both rankings with Reciprocal Rank Fusion.

| Method | Recall@3 | MRR |
|---|---|---|
| BM25 | **86 %** | **0.82** |
| Dense | 64 % | 0.61 |
| Hybrid (RRF) | 79 % | 0.65 |

Embeddings recover the vocabulary-gap question BM25 misses (*keep defence costs low* vs *austerity*), and the hybrid also recovers *undersea cables*. But they miss questions that hinge on a rare term or proper noun (*Golden Dome*, *Barkhane*, *Salisbury*, *open seas protection*): a 200-word chunk embedding dilutes a single specific detail that BM25 weighs heavily.

Caveat: the questions were written from keywords found in the documents, which favours lexical matching, and 14 questions is a small sample (one question = 7 points). Next step: a set of paraphrased questions, and a hybrid that weights BM25 more.

### 3. Retrieval misses the expected document

The expected source (France 2021) talks about *seabed warfare* and *submarine cables*, so BM25 does not retrieve it. The model stays grounded in the passages it receives and flags its interpretation instead of inventing an answer.

```
$ python src/cli.py "What new area of confrontation involves undersea cables?"

The sources point to maritime areas. Maritime areas are subject to rising tensions because of
their key role in globalisation, including data flows carried by undersea cables [1]. The
sources don't use the phrase "new area of confrontation," so this is my reading of what they
describe.

Undersea cables also appear as a vulnerability. Threats from third-party interference can
extend to digital infrastructure such as undersea cables [2]. More broadly, competition over
global commons, including sea, is intensifying [3].

Sources:
[1] france_2017_DefenseAndNationalSecurityStrategicReview.txt (chunk 95, score 14.50)
[2] spain_2021_NationalSecurityStrategy.txt (chunk 24, score 12.44)
[3] france_2017_DefenseAndNationalSecurityStrategicReview.txt (chunk 94, score 11.99)
```

## How it works

1. **Ingestion** (`src/ingest.py`): loads `.txt` and `.md` files and splits them into 200-word chunks with a 40-word overlap.
2. **Retrieval** (`src/retrieve.py`): BM25 scoring (k1 = 1.5, b = 0.75) after lowercasing and removing English stop words (`src/stopwords.py`).
3. **Generation** (`src/generate.py`): builds a prompt with numbered sources and asks the model to answer only from them.
4. **Evaluation** (`src/evaluate.py`): computes Recall@k and MRR, and sweeps the score threshold.

## Usage

Requires Python 3.10 or later.

```bash
# Tests (14 unit tests)
python -m unittest discover -s tests -v

# Ask a question (shows the retrieved passages without an API key)
python src/cli.py "Which country is the pacing challenge for the US Department of Defense?"

# Evaluate retrieval
python src/evaluate.py
```

For written answers, install the optional dependency and set an API key:

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="your_key"
```

## Data

The documents come from the [Military Doctrines dataset](https://jandresgannon.github.io/militarydoctrines/) (J Andrés Gannon, Vanderbilt University), which collects national security strategy documents in text format.
